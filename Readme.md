# Teacher & Course Review App

## How to Run This Project

This project is ready to run. You just need to download it and open it in Android Studio.

1.  **Get the Code:**
    * In Android Studio, go to `Get from VCS`.
    * Paste this URL: `https://github.com/Nishant-Mahto/TeacherCourseReview.git`
    * Click `Clone`.
    * Or, you can just click the "Code" button on GitHub and "Download ZIP"

2. 
    * Open the project in Android Studio.
    * Wait 1-2 minutes for it to sync and build.

3. 
    * Click the **Green Play Button (►)**.
