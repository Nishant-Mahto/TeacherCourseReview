# Teacher & Course Review App 📱

A high-performance **Native Android** solution designed to modernize academic feedback.

## Engineering Highlights
* **Stack**: Kotlin & Android Studio (Native Performance).
* **Architecture**: BaaS model using **Google Firebase**.
* **Smart Core**: Hybrid Sentiment Analysis Engine (Star Rating + Keyword Correlation).
* **Latency**: <1s synchronization using Firebase Realtime Database.

## Engineering Fixes
* **Regional Connectivity**: Reconfigured SDK to target `asia-southeast1` regional endpoints to fix silent write failures.
* **Serialization**: Resolved NoSQL data mapping issues by implementing manual no-argument constructors for Kotlin Data Classes.

## Beta Results
* **Success Rate**: 100% data sync across 20+ test submissions.
* **Latency**: Verified sub-second real-time persistence.

## Run Instructions
1. Clone the repo.
2. Open in Android Studio (Hedgehog+).
3. Build and hit **Run**.
